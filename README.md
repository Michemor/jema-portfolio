## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) v16 or higher

### Run locally

```bash
# 1. Install dependencies (first time only)
npm install

# 2. Start the dev environment — watcher + live server in one command
npm run dev
```

This opens the portfolio at **http://localhost:3000** and watches `assets/dashboards/` for new images.

### Add a dashboard

1. Drop any image (`.png`, `.jpg`, `.webp`) into `assets/dashboards/`
2. The watcher auto-updates `assets/manifest.json`
3. Reload the browser — the new card appears automatically

### Deploy to Cloudflare Pages

```bash
git add assets/
git commit -m "Add new dashboard"
git push   # Cloudflare Pages auto-deploys
```
